Bloom Filter Visualizer

A Bloom filter uses an m-bit array and k independent hash functions. Inserting an item sets all k hashed bit positions to 1. Querying checks those k positions: any 0 guarantees the item is absent; all 1s means it is probably present (false positives are possible, false negatives are not).

Insert or check a value to see its k hash probes.
