# Forge v0.01dev-alpha

This alpha establishes the first real end-to-end Forge workflow:

1. Register a local repository
2. Browse revisions, files, and bookmarks with Git and `jj` providers
3. Open a change request between source and target bookmarks
4. Leave reviews and threaded line comments across review rounds
5. Trigger CI, inspect job logs, and download generated artifacts

## Highlights

- Go + chi + server-rendered HTML architecture
- SQLite persistence with goose migrations
- `jj` CLI adapter plus Git fallback adapter
- Bookmark-based change requests and review rounds
- Local CI execution with pipeline import from `.forge/pipeline.yml`
- Local artifact storage and download
- Single-user settings and repository registration flow

## Notes

- See [known limitations](../known-limitations.md) for alpha constraints.
- This release is aimed at validating the `git`-backed, `jj`-oriented forge workflow rather than polishing every surface.
- A terminal demo transcript of the end-to-end flow is included at [`v0.01dev-alpha-demo.typescript`](./v0.01dev-alpha-demo.typescript).
