# 🎯 Problem (Why)
Glean needs strongly typed core records so ingestion, graph traversal, and UI rendering stay consistent and auditable.

# 📋 Acceptance Criteria
- [ ] Shared schemas validate all write paths.
- [ ] Model versioning strategy is defined.
- [ ] Contract tests enforce model compatibility.

# 🚫 Negative Constraints
- Do not allow untyped payload persistence in core storage.
- Do not collapse provenance fields into optional free-form blobs.
