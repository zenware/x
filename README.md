# x

Experimental polyglot monorepo — any language, any state of completeness.

Contains applications, libraries, services, scripts, and interactive demos. Inspired by [Xe/x](https://github.com/Xe/x), without limiting to a single language.

Ultimately this is a playground; projects that mature may graduate to their own repositories.

## Interactive Demos (GitHub Pages)

Live site: **https://zenware.github.io/x/**

- [Bloom Filter Visualizer](https://zenware.github.io/x/bloom-filter/) — interactive bit array, *k*-hash probing, and false-positive explorer

Static demos live in `site/` and deploy automatically via `.github/workflows/pages.yml`.
